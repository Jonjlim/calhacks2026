What stays real

  • Memories still go through the same private-to-published rule. The "send it up" tap is the publish tap.
  • Council lines come from real agent events and decisions. A bubble appears only when one was recorded.
  • Dropped gifts use the real "Dropped X because…" event, with its citation.
  • Prices and stock still come from the stored listing, never from a bubble.

What it needs from each dev

  • Dev 1: a floating prompt layer, a note-to-spark animation, and bubble and chip components anchored to bots.
  • Dev 3: a one-step "next beat" selector, so the room shows one prompt at a time, plus bubble-ready event text.
  • Dev 2: no schema change. The existing memory, clue and vote calls cover every beat.
  • Dev 4: product images for the landing boxes, so gifts are not plain wrapped cubes.
